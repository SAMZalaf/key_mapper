# Keyboard Mapper Pro - النسخة الاحترافية المطورة

## 🎯 نظرة عامة

تطبيق احترافي لإدارة الأزرار الافتراضية مع ميزات متقدمة للتحكم الكامل في كل زر.

## ✨ المزايا الرئيسية

### 1. واجهة أحادية النافذة
- نافذة واحدة فقط تحتوي على منطقة العمل والشريط الجانبي
- لا توجد نوافذ منبثقة مزعجة
- تصميم عصري وأنيق

### 2. أزرار قابلة للسحب والتحريك
- سحب وإفلات سهل للأزرار في أي مكان
- شبكة ذكية (Grid Snap) لمحاذاة تلقائية
- تغيير الحجم بالماوس (Ctrl + عجلة الماوس)

### 3. قائمة سياق متقدمة (زر أيمن)
كل زر يحتوي على قائمة إجراءات كاملة:
- ✂️ **قص** - قص الزر للحافظة
- 📋 **نسخ** - نسخ إعدادات الزر
- 📌 **لصق** - لصق زر جديد من الحافظة
- ⚙️ **خصائص متقدمة** - تحرير شامل لكل الخصائص
- 🎨 **تغيير اللون** - اختيار لون الزر
- 🖌️ **لون الضغط** - لون الزر عند الضغط
- 🌟 **لون التمرير** - لون الزر عند مرور الماوس
- 📏 **تغيير الحجم** - ضبط العرض والارتفاع
- 🔲 **حدود الزر** - سمك ولون الحدود
- 🎯 **حساسية فردية** - حساسية خاصة لكل زر
- 💡 **تأثيرات** - تأثيرات الضغط والتوهج
- 📝 **Tooltip** - نص تلميح عند المرور
- 🔄 **تكرار** - إنشاء نسخة مطابقة
- 🗑️ **حذف** - إزالة الزر

### 4. خصائص متقدمة لكل زر

#### الخصائص الأساسية:
- اسم الزر (Label)
- المفتاح المرتبط (Key Bind)
- نوع الإجراء (key, mouse_click, macro, text, combo)
- القيمة/الإجراء

#### خصائص المظهر:
- حجم الخط (8-30)
- سمك الحدود (0-10)
- تأثير الضغط (none, scale, color, both)
- تفعيل التوهج

#### خصائص التأثيرات:
- تأثير الضغط المتحرك
- التوهج مع لون قابل للتخصيص
- ألوان مخصصة للضغط والمرور

### 5. حساسية فردية لكل زر
- نطاق الحساسية: 0.1 إلى 10.0
- حساسية عالية = تنفيذ أسرع
- حساسية منخفضة = تنفيذ أبطأ
- مستقلة عن الحساسية العامة

### 6. تفعيل فوري
- النقر على الزر يُفعّل الإجراء فوراً
- دعم الضغط المستمر والإفلات
- استجابة فورية للمفاتيح المرتبطة

### 7. الشريط الجانبي الذكي
- إضافة أزرار جديدة
- وضع التعديل (Ctrl+E)
- الحساسية العامة
- ضبط الشبكة
- إحصائيات الأزرار
- حفظ/تحميل التخطيطات
- تسجيل الماكرو
-_undo_/Redo_

### 8. أنواع الإجراءات المدعومة

#### Key (مفتاح):
- محاكاة ضغط مفاتيح فردية
- دعم المفاتيح الخاصة (Space, Enter, Shift, Ctrl, Alt...)

#### Mouse Click (نقر الماوس):
- نقرة يسرى/يمنى/وسطى
- نقرة مزدوجة

#### Text (نص):
- كتابة نصوص كاملة
- دعم اللغة العربية والإنجليزية

#### Macro (ماكرو):
- تسجيل سلسلة إجراءات
- تشغيل متتابع

#### Combo (تركيبات):
- تركيبات مفاتيح متعددة
- مثل: Ctrl+C, Alt+Tab

### 9. ميزات إضافية

#### حفظ وتحميل التخطيطات:
- حفظ التخطيط كملف JSON
- تحميل تخطيطات محفوظة
- تخطيطات افتراضية جاهزة

#### Undo/Redo:
- تراجع عن آخر إجراء (Ctrl+Z)
- إعادة الإجراء (Ctrl+Y)

#### الحفظ التلقائي:
- حفظ تلقائي كل 30 ثانية
- استعادة التخطيط عند البدء

#### إحصائيات:
- عدد الأزرار
- حالة التطبيق
- معلومات الأداء

## 📖 دليل الاستخدام السريع

### إضافة زر جديد:
1. اضغط على "➕ إضافة زر جديد" في الشريط الجانبي
2. اسحب الزر للمكان المطلوب
3. انقر بزر الماوس الأيمن لتحرير الخصائص

### ربط مفتاح:
1. انقر بزر الماوس الأيمن على الزر
2. اختر "خصائص متقدمة"
3. أدخل المفتاح في حقل "المفتاح المرتبط"
4. احفظ التغييرات

### تغيير الحساسية:
1. انقر بزر الماوس الأيمن على الزر
2. اختر "حساسية فردية"
3. اضبط القيمة المطلوبة
4. اضغط "تطبيق"

### وضع التعديل:
- اضغط Ctrl+E للتبديل بين وضع التعديل ووضع التشغيل
- في وضع التعديل: يمكنك تحريك وتعديل الأزرار
- في وضع التشغيل: الأزرار تستجيب للمفاتيح المرتبطة

## 🎨 تخصيص الألوان

كل زر يدعم 4 ألوان:
1. **اللون الأساسي**: لون الزر العادي
2. **لون الضغط**: يظهر عند النقر
3. **لون التمرير**: يظهر عند مرور الماوس
4. **لون التوهج**: إطار مضيء حول الزر

## ⚡ نصائح الأداء

- استخدم الحساسية العالية للأزرار التي تحتاج استجابة سريعة
- فعّل التوهج للأزرار المهمة لتمييزها بصرياً
- استخدم Tooltip لوصف وظيفة كل زر
- احفظ تخطيطات مختلفة لاستخدامات متعددة

## 🔧 اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|----------|---------|
| Ctrl+E | تبديل وضع التعديل |
| Ctrl+S | حفظ التخطيط |
| Ctrl+O | تحميل تخطيط |
| Ctrl+N | زر جديد |
| Ctrl+Z | تراجع |
| Ctrl+Y | إعادة |
| Ctrl+R | تسجيل ماكرو |
