# Keyboard Mapper Pro V3 - النسخة الاحترافية المتقدمة

## 🎯 المزايا الجديدة

### ✅ تتبع شامل للمدخلات
- **تتبع ضغطات المفاتيح**: تسجيل كل ضغطة مع التوقيت
- **تتبع حركات الماوس**: مراقبة حركة الماوس وإحداثياته
- **تتبع النقرات**: تسجيل جميع نقرات الماوس (أيمن، أيسر، أوسط)
- **سجل أحداث مباشر**: عرض فوري لجميع الأحداث في الشريط الجانبي
- **إحصائيات شاملة**: عدد الضغطات، النقرات، المفاتيح النشطة، موقع الماوس

### 🖱️ واجهة مستخدم محسّنة
- نافذة واحدة فقط مع سايدبار للإعدادات
- Canvas قابل للتمرير مع شبكة خلفية
- أزرار قابلة للسحب والتحريك بحرية
- قائمة سياق متقدمة بالزر الأيمن

### ⚙️ خصائص متقدمة لكل زر
- تحرير الاسم والمفتاح المرتبط والإجراء
- تغيير اللون والحجم والخط
- حساسية فردية لكل زر (0.1 - 5.0)
- تأثيرات بصرية (تكبير، لون، توهج)
- عداد ضغطات مدمج في كل زر
- Tooltip يعرض المعلومات عند التمرير

### 📊 لوحة تتبع المدخلات
- عرض إحصائيات حية
- سجل الأحداث القابل للتمرير
- أزرار التحكم (بدء، إيقاف، تصدير، مسح)
- تصدير السجل إلى ملف JSON

### 🎮 أنواع الإجراءات المدعومة
- **Key**: محاكاة ضغط مفاتيح فردية
- **Mouse Click**: محاكاة نقرات الماوس
- **Macro**: تنفيذ مجموعات مفاتيح
- **Text**: كتابة نصوص
- **Combo**: تنفيذ متتابعات مفاتيح

## 🚀 التشغيل

```bash
python3 keyboard_mapper_pro_v3.py
```

## 📝 طريقة الاستخدام

1. **إضافة زر**: انقر على "➕ إضافة زر جديد" في الشريط الجانبي
2. **تحريك الزر**: اسحب الزر بالماوس لوضعه في المكان المطلوب
3. **تحرير الخصائص**: انقر بالزر الأيمن → "خصائص متقدمة"
4. **ربط مفتاح**: أدخل المفتاح المرتبط (مثل: a, enter, f1, ctrl_l)
5. **ضبط الحساسية**: استخدم عجلة الماوس فوق الزر أو من القائمة
6. **تفعيل الزر**: انقر على الزر لتنفيذ الإجراء فوراً

## 🎯 ميزات التتبع

- يتم تسجيل جميع الأحداث تلقائياً عند بدء التطبيق
- يمكن إيقاف/بدء المراقبة من الأزرار في الشريط الجانبي
- يتم حفظ آخر 1000 حدث في الذاكرة
- يمكن تصدير السجل الكامل إلى ملف JSON
- تحديث الإحصائيات كل 500ms

## 📦 المتطلبات

```bash
pip install pynput pyautogui
```

## 💾 حفظ وتحميل التخطيطات

- **حفظ**: احفظ تخطيط الأزرار الحالي في ملف JSON
- **تحميل**: استعد تخطيطاً محفوظاً سابقاً
- **مسح الكل**: احذف جميع الأزرار من الواجهة

## 🔧 التقنيات المستخدمة

- **Tkinter**: واجهة المستخدم الرسومية
- **Pynput**: مراقبة وتحكم في لوحة المفاتيح والماوس
- **Pyautogui**: أتمتة إضافية (اختياري)
- **JSON**: حفظ وتحميل البيانات
