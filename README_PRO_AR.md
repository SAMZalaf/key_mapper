# 🎹 KeyboardMapper Pro - دليل التوثيق الشامل

## 📋 نظرة عامة
تطبيق محاكي لوحة المفاتيح والماوس المتقدم لنظام ويندوز، مصمم خصيصاً للمحاكيات والألعاب. يتميز بواجهة عصرية، استهلاك منخفض للموارد، وميزات متقدمة لا مثيل لها.

---

## ✨ الميزات الرئيسية

### 🎮 المحاكاة المتقدمة
- **لوحة مفاتيح افتراضية كاملة**: 60 مفتاح قابل للتخصيص
- **محاكاة اللمس**: دعم كامل لحركات اللمس المتعددة
- **تحكم بالماوس**: نقرة، سحب، حركة دقيقة
- **استجابة فورية**: زمن استجابة <10ms

### ⚙️ إعدادات متقدمة
- **الشفافية**: من 1% إلى 100% مع تحكم دقيق
- **تحرير الماوس**: تفعيل/إيقاف بـ F2
- **تشغيل/إيقاف التخطيط**: زر سريع بـ F1
- **وضع التعديل**: سحب وإفلات المفاتيح بـ Ctrl+E

### 🎨 تخصيص كامل
- **5 ثيمات جاهزة**: داكن، فاتح، أزرق، أخضر، برتقالي
- **تغيير حجم المفاتيح**: من 30 إلى 200 بكسل
- **إعادة تموضع المفاتيح**: حرية كاملة في الترتيب
- **شبكة ذكية**: محاذاة تلقائية (5-50 بكسل)

### 📊 نظام التسجيل
- **تسجيل الإجراءات**: حفظ كل ضغطة وحركة
- **الإحصائيات الحية**: عدد الأحداث، الوقت، الأداء
- **حفظ بصيغة JSON**: مشاركة وسهولة التحرير
- **تشغيل التسجيل**: إعادة تنفيذ الإجراءات المسجلة

## 🚀 التثبيت والاستخدام

### الطريقة 1: التشغيل المباشر (للمطورين)
```bash
# تثبيت المتطلبات
pip install tkinter

# تشغيل التطبيق
python keyboard_mapper_pro.py
```

### الطريقة 2: الملف التنفيذي (موصى به)
```bash
# على نظام ويندوز، شغل ملف البناء
build_windows.bat

# أو يدوياً
pip install pyinstaller
pyinstaller --onefile --windowed --name KeyboardMapperPro keyboard_mapper_pro.py
```

**الملف الناتج**: `dist/KeyboardMapperPro.exe`

## ⌨️ اختصارات لوحة المفاتيح

| الاختصار | الوظيفة | الوصف |
|----------|---------|-------|
| **F1** | ▶️⏸️ تشغيل/إيقاف | تفعيل أو إيقاف محاكاة التخطيط |
| **F2** | 🖱️ تحرير الماوس | قفل/فتح التحكم بالماوس خارج التطبيق |

| **Ctrl+O** | 📂 فتح | تحميل تخطيط محفوظ |
| **Ctrl+N** | 📄 جديد | إنشاء تخطيط جديد |
| **Ctrl+Scroll** | 📏 تغيير الحجم | تعديل حجم المفتاح المحدد |

## 🎯 دليل الاستخدام التفصيلي

### 1️⃣ التشغيل الأولي
1. شغل `KeyboardMapperPro.exe`
2. ستظهر واجهة رئيسية مقسمة لـ 4 تبويبات
3. لوحة المفاتيح الافتراضية جاهزة للاستخدام فوراً

### 2️⃣ تخصيص المفاتيح
**وضع التعديل (Ctrl+E)**:
- انقر على أي مفتاح لتحديده
- اسحب المفتاح لتغيير مكانه
- استخدم Ctrl+Scroll لتغيير الحجم
- انقر مزدوج لتغيير الوظيفة

**الشبكة الذكية**:
- فعّل الشبكة من تبويب "مظهر"
- اختر حجم الشبكة (5-50 بكسل)
- المفاتيح ستلتقط تلقائياً لأقرب نقطة

### 3️⃣ التحكم بالشفافية
1. اضغط F3 لتفعيل وضع الشفافية
2. استخدم شريط التمرير لضبط النسبة (1-100%)
3. التغييرات تُطبق فوراً
4. احفظ الإعدادات للاحتفاظ بالنسبة

### 4️⃣ تسجيل الإجراءات
1. اذهب لتبويب "تسجيل"
2. اضغط "بدء التسجيل"
3. نفذ الإجراءات المطلوبة
4. اضغط "إيقاف التسجيل"
5. احفظ الملف أو شغله مباشرة

### 5️⃣ تحسين الأداء
من تبويب "أداء":
- **معدل الإطارات**: اضبط بين 15-144 FPS
- **V-Sync**: فعّل لمنع التمزق
- **التسريع العتادي**: حسّن الاستجابة
- **جودة الرسم**: عدّل حسب الحاجة

## 🛠️ حل المشاكل

### ❌ التطبيق لا يفتح
```bash
# تأكد من تثبيت Visual C++ Redistributable
# حمّل من: https://aka.ms/vs/17/release/vc_redist.x64.exe
```

### ❌ المفاتيح لا تستجيب
1. تأكد من ضغط F1 لتفعيل التخطيط
2. شغل التطبيق كمسؤول (Run as Administrator)
3. تحقق من عدم تعارض مع برامج أخرى

### ❌ الشفافية لا تعمل
1. اضغط F3 لتفعيل الوضع
2. تأكد أن نسبة الشفافية ليست 100%
3. أعد تشغيل التطبيق

### ❌ الملف التنفيذي كبير جداً
```bash
# استخدم UPX للضغط
upx --best dist/KeyboardMapperPro.exe
```
